# 带你了解卵巢过度刺激综合征

> 更新时间：2026-09-17 (UTC+8)

卵巢过度刺激综合征（OHSS）是卵巢在过度激素的刺激下，引起卵巢形态改变及产生过多的卵巢激素而导致的一种综合性病症，是辅助生殖技术的一种并发症，与促排卵有关。
**那么哪些情况容易引起OHSS呢？**
★治疗周期血E2高★卵泡发育数目>30个★多囊卵巢综合征（PCOS）★年龄<35岁瘦小者★敏感体质

**卵巢过度刺激综合征有哪些具体表现呢？**

**轻度刺激：**一般表现为下腹不适，轻度腹胀痛，胃纳差，B超测卵巢直径≤5cm，一般发生于注射HCG7-10天；

**中度刺激：**一般表现为明显下腹胀痛，恶心，呕吐或伴腹泻，腹围增大，体重增加≥3kg；明显腹水，少量胸水，双侧卵巢明显增大，直径达5-10cm；

**重度刺激：**表现为腹胀痛加剧，腹水明显增加，可致呼吸困难，不能平卧，大量胸水、腹水致心功能障碍、血液浓缩、急性肾衰等，卵巢直径≥10cm。

**确诊了卵巢过度刺激综合征，该如何治疗呢？**
OHSS是一种自限性疾病，如无妊娠通常10-14天会快速自行消退。如需提供支持治疗，首先帮助患者渡过这一时期，避免发生更严重的并发症，并做到以下几点：
# ONE
• 注意休息，高蛋白饮食• 严密观察：体重、腹围，记录出入量• 避免剧烈活动以防止增大的卵巢发生扭转和囊内出血• 停用任何促性腺激素纠正低血容量（应用白蛋白、低分子右旋糖酐等）• 改善毛细血管通透性• 腹压增加，胸水腹水明显可穿刺引流• 注意预防卵巢破裂/蒂扭转• 必要时终止妊娠（治疗性人工流产）总之，一定要遵医嘱！
